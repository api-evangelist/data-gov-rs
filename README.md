# data.gov.rs (data-gov-rs)

data.gov.rs is the national government open-data portal for the Republic of Serbia, running the **uData** platform and exposing the uData REST API over ~3,452 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-gov-rs/refs/heads/main/apis.yml)

## Type
- **kind:** government  ·  **software:** uData

## API
- **data.gov.rs uData REST API** — base `https://data.gov.rs/api/1`. [Docs](https://udata.readthedocs.io/en/stable/api/) · [Portal](https://data.gov.rs/en/)
- Live endpoint verified: `https://data.gov.rs/api/1/site/` · 3,452 datasets reported
- Datasets search: `https://data.gov.rs/api/1/datasets/?page_size=1`
